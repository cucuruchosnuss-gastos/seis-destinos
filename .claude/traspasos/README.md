# Traspasos pendientes

Cada archivo acá es un prompt que un subagente de módulo dejó escrito al cerrar su trabajo, para que el chat de arquitectura lo aplique sobre CLAUDE.md o lo derive al chat de permisos.

Se escriben acá y no se devuelven como texto porque la respuesta de un subagente no le llega a la persona: la recibe el agente que lo invocó. Un archivo, en cambio, viaja en el commit y aparece en el patch que se audita.

Cuando un traspaso ya se aplicó, se borra el archivo. Una carpeta vacía significa que no hay nada pendiente.
