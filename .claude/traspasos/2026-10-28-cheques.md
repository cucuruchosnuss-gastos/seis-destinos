## Qué cambió y por qué

Pedido de Facu: sin pasos de más. Cuando el banco acredita cheques que se le mandaron, el gasto del banco se tiene que crear SOLO, en el mismo paso de acreditar. VENTA: el banco acredita el neto (1.000.000 → 980.000) y la diferencia es el gasto. DEPÓSITO: entra el importe completo y los gastos del banco salen aparte.

La base ya estaba cambiada (la cambió el chat de la base el 27/10/2026; leída con `pg_get_functiondef` el 28/10/2026): `acreditar_cheques(p_items jsonb, p_fecha date)` con ítems `{cheque_id, acreditado}` (venta, 0 < acreditado <= importe) o `{cheque_id, gastos}` (depósito, 0 <= gastos < importe); crea el gasto en "Gastos bancarios y comisiones" (uno por cuenta y modo) y devuelve un renglón por cuenta y modo `{cuenta, modo, cheques, bruto, acreditado, gastos, caja_movimiento_id, gasto_id}`. El cheque queda `vendido`/`depositado` con `venta_gasto_id` en los dos si hubo gasto. Claude Code no tocó la base (solo SELECT).

En la cartera (sección Cheques de `modulos/administracion.html`, solo dentro de la región `CHEQUES: inicio/fin`):
- «En el banco» en dos bloques, "Vendidos · esperando acreditación" y "Depositados · esperando acreditación", cada uno con su total.
- "Cargar lo acreditado": por cheque, "Monto acreditado" (venta; viene el importe) o "Gastos del banco" (depósito; viene 0), con el texto en vivo ("Diferencia $ X (Y %) → se carga como gasto" / "Se acredita $ importe · gasto $ X"), validado con las mismas reglas que la base antes de mandar. Montos con el parser argentino de `js/utils.js` (`leerNumeroAr`, que la región ahora importa; `js/utils.js` no se tocó).
- El aviso final y el resultado dicen qué gastos creó la base (por cuenta y modo, con "Ver el gasto") o que no se creó ninguno.
- Se sacó el botón "Cargar el gasto del banco" (`a[data-gastos-banco]`, `htmlGastosBanco`, `unidadUnicaDe`, `CATEGORIA_GASTOS_BANCARIOS`, CSS `.chq-gastos-banco*`). Con "Ya se acreditó" (un solo paso, `depositar_cheques`/`vender_cheques`, que no cambiaron y no cargan gasto) el resumen dice que así no se carga ningún gasto y cómo cargarlo.
